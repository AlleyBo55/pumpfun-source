## Account mappings and branches

sites.json retains each exact old site ID, method arguments and complete IDL order/flags/address/PDA/relations, plus supplied/omitted expressions. The six AMM methods call the same tradeV2Accounts helper: pool/user/global config; base/quote mints; user base/quote accounts; pool base/quote accounts; base/quote token programs; system program; user-volume PDA; fee-config PDA; buyback recipient quote ATA; event authority and program. The helper receives globalConfig state but supplies the static GLOBAL_CONFIG_PDA account address. Recipient selection reads globalConfig.buybackFeeRecipients using Math.random; canonical ATA derivation uses pool.quoteMint, selected wallet, allowOwnerOffCurve=true and quoteTokenProgram. Selection is symbolic here; no recipient, PDA or ATA was numerically computed. Empty list/malformed state is not validated by this review.

AMM raw numeric mapping is direct: buyV2(baseOut,maxQuoteIn), buyExactQuoteInV2(spendableQuoteIn,minBaseOut), sellV2(baseIn,minQuoteOut). Raw builders do not compute slippage or a quote. withBuyAccounts uses quote input/max budget and base output; withSellAccounts uses base input and quote output. Shared setup wraps native input, ensures missing canonical output ATA and closes native output; custom non-ATA account existence is a caller/state responsibility. High-level routing chooses V2 only when options.v2 and supportsTradeV2(pool), whose source predicate is !pool.isCashbackCoin; direct raw V2 methods do not independently apply that routing predicate.

Pump tradeV3Accounts normalizes absent/zero/native quote to NATIVE_MINT, derives bondingCurvePda(mint), base ATAs and quote ATAs for curve/user, and supplies user/token programs. Legacy quote buyback is the supplied wallet or a random static listed wallet; token quote is the supplied/default-first wallet's quote ATA. Seven omitted accounts are global,bondingCurve,userVolumeAccumulator,feeConfig,systemProgram,eventAuthority,program. Their exact IDL recipes and flags are retained; Anchor resolution was not invoked, so IDL recipes are not a claim those omissions resolve for arbitrary inputs.

Pump high-level wrappers reject isCashbackCoin before composing. Sell token quote prepends user's quote ATA and buyback ATA before raw; legacy quote skips them. buybackAtaInstructions uses the same explicit/default-first wallet branch on token quotes; default legacy random selection is inside the raw helper and requires no buyback ATA setup. ## Numeric quote/fees/slippage mapping

No numeric JavaScript/BN code was executed. Raw parameters are caller values; sites.json binds their exact IDL argument types and order. Fixed line witnesses and whole source preserve the arithmetic rather than substituting a hand-created oracle.

AMM high-level buyBaseInput/buyQuoteInput consume pool reserves, virtual quote reserves, mint supply/account, coinCreator/creator, feeConfig/globalConfig, quote mint, mayhem/configurable creator rates and quoteTransferFee. V2 buyDebit computes booked=net+LP+protocol+creator; buyback=floor(protocol*buybackBasisPoints/10000) for nonmayhem V2, otherwise0; vault V2=booked−buyback (V1=net+LP); debit=booked+grossForTransferFee(vault)−vault. ExactQuoteInFees floor-divides budget*10000/(10000+total rates), uses the retained fee helper for component fees, then shaves excess from net without recomputing those fee fields. High-level buy slippage uses floor((1+s/100)*1e9) then BN multiply/divide. Sell pricing uses virtual quote reserves, a real-payout bound quoteReserve−(protocolFees+creatorFees), fee subtraction/quote-transfer net and floor((1−s/100)*1e9). The retained source includes rounding and zero/error checks; comments alone are not substituted for executable definitions.

Pump wrapper buy max quote is q+floor(q*floor(s*10)/1000); exact-buy minimum is max(amount−floor(amount*floor(s*10)/1000),1); sell minimum uses the same subtraction with floor0. This quantizes requested slippage to tenths-of-percent units before BN arithmetic; no new range/finite/negative-input validation is inferred. Quote helpers are separate calls, not automatically executed by the raw builders.

The retained Pump v3 quote helpers derive fee rates from global/feeConfig, mint supply (fixed billion for nonmayhem), virtual reserves, quote mint and configurable creator fee, setting creator rate0 when creator is zero. ceilFee=(amount*bps+9999)/10000; buyback is floor(ceilProtocolFee*buybackBps/10000),0 on mayhem. v3BuyDebit grosses curve-bound net+fees less buyback (including optional pool leg), then adds buyback. Exact-budget net is floor-divided then shaved by excess. Quote helpers branch on complete/zero reserves, remaining supply, mayhem, curveBaseTokenBalance and pool-to-be liquidity/migration fee. These source branches are documented only; no stopped V3 crossing/partial-fill or token-extension experiment is resumed, and SDK comments attributing target errors/semantics are not independently validated.
