# Exact-case publication read guard

`exact_case_guard.py` runs only a publication's documented passive `verify.py`, optionally its saved-only crypto mode. A Python audit hook intercepts every publication-scoped `open` event, including builtins.open, io.open/Path.open and importlib file reads. Every requested path component is compared with actual directory-entry names via os.listdir, starting at /. It does not use Path.exists(), resolve(), lowercasing, aliases or symlinks to make incorrect spellings pass. Scope detection is casefold-based so an incorrectly cased root cannot silently escape the guard. Trusted Python and crypto runtime paths outside the publication are excluded; this is a path-spelling validator, not a security/network sandbox.

The guard refuses case violations even if the publication happens to catch the resulting FileNotFoundError. It records each valid open and every rejected path in an external observation file. It does not mutate publication inputs or execute archived controllers, harnesses, VMs, compilers or original decoders.

The frozen96f43 default verifier failed under the guard. After1,556 valid publication opens, it attempted acceptance-plan/MANIFEST.json although the actual entry is manifest.json. Its `.exists()`-based optional uppercase branch succeeds on case-insensitive APFS and triggers the alias read. Independent directory-entry inspection also found copy-bindings declared build-plan/manifest.json and held/build-plan-v1/manifest.json while actual filenames are MANIFEST.json. Those lower-case reads would fail on Linux. The original failure streams and structured observation are retained. No frozen96 files changed.

This is evidence about this specific uncommitted96 publication. The older090 collector package correctly declares and reads build-plan/MANIFEST.json and is not implicated by this finding. New wrappers should preserve exact entry spellings, strict membership and original packet bytes, then pass this guard in both default and supported Python3.12/Solders saved-only crypto modes. No runtime acceptance needs to rerun for this filesystem portability correction.
